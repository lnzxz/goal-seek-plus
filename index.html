Goal Seek Plus

A fast, accurate Goal Seek for Google Sheets™

Know the result you need, but not the input that gets you there? Goal Seek Plus changes one input cell until a formula reaches your target: the break-even price, the interest rate behind a payment, the sales volume that hits a commission tier.

  • Fast: typical models solve in a couple of seconds, using as few recalculations as possible.
  • Honest: if no input reaches your target (for example a tiered SUMIFS or IF that jumps past it), it tells you so and shows the closest result instead of a wrong answer.
  • Less typing: picks up the selected cell and remembers your last setup on each sheet.
  • Undo: one click puts the original value back.
  • Private: it only accesses the spreadsheet you open it in, and nothing is sent anywhere.

How to use it

  1. Open your spreadsheet and choose Extensions → Goal Seek Plus → Open Goal Seek.
  2. Set cell: the cell containing the formula whose result you want (select it and click Use selected).
  3. To value: the result you want that formula to show.
  4. By changing cell: the input value Goal Seek is allowed to change. It must contain a number, not a formula.
  5. Click Solve. Click Restore original value to undo.

Support & FAQ

It says "No exact solution"

Your formula jumps past the target value (common with tiers, IF, lookups, ROUND). Goal Seek Plus shows the input where the jump happens. Check whether your target is actually achievable.

It says "Target not reached"

No input value tried gets the formula to your target. For example, a square can never be negative. The closest result found is shown.

It says the input does not change the target

The "Set cell" formula doesn't depend on the "By changing cell". Check that you picked the right cells.

Something else?

Email goalseekplus@lnz.gg and include what you tried. Screenshots help.
